手机自动投递 · 第 1 步

复制脚本到 Hamibot 跑一次，只读不点，安全。
1

点下面按钮，脚本自动进剪贴板

2

打开 Hamibot → 首页「+」新建脚本 → 名字随便写 → 长按输入区粘贴 → 保存

3

先手动停在 BOSS 岗位详情页（能看到「立即沟通」那屏），回 Hamibot 点运行

4

日志出来 → 右上角复制 → 发给我

脚本全文（按钮失灵时手动复制）
/**
 * 手机自动投递 · 第 1 步：探测当前界面
 * 作用：只读不点。把当前屏幕上所有可点的文字打出来，复制发给我，
 *      我照着你的机型写精确点击版。
 *
 * 用法：
 *   1. 手机装 AutoX.js（开源免费，见说明.md）
 *   2. 授予无障碍权限
 *   3. 先手动翻到"BOSS直聘 / 猎聘"的某个岗位详情页
 *   4. 运行本脚本，3 秒后开始扫描
 *   5. 屏幕顶部会显示日志，点右上角复制，发我
 */
auto.waitFor();
toastLog("3 秒后开始扫描，请现在就停在岗位详情页");
sleep(3000);

var 屏幕宽 = device.width;
var 屏幕高 = device.height;
toastLog("屏幕 " + 屏幕宽 + "x" + 屏幕高 + "，开始扫");

var 结果 = [];
var 控件 = classNameMatches(/TextView|Button|EditText|ImageView/).find();
for (var i = 0; i < 控件.size(); i++) {
    var w = 控件.get(i);
    var 文 = (w.text() || "").trim();
    var 述 = (w.desc() || "").trim();
    if (!文 && !述) continue;
    if (文.length > 30) 文 = 文.substring(0, 30) + "…";
    var b = w.bounds();
    var 行 = w.className().replace("android.widget.", "") +
          " | 文字:" + 文 + " | 描述:" + 述 +
          " | 位置:" + b.left + "," + b.top + " 大小:" + b.width() + "x" + b.height();
    结果.push(行);
    console.log(行);
}
toastLog("扫完，共 " + 结果.length + " 个控件，点右上角复制日志发我");
复制失败多半是浏览器拦了剪贴板，点「全选」再长按复制一样能用
